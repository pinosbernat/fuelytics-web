# fuelytics-web

Sitio público de **Fueltic**, la app de registro de repostajes y consumo real.

- [Política de privacidad](https://fueltic.com/privacidad.html)
- [Eliminar tu cuenta](https://fueltic.com/eliminar-cuenta.html)
- [Unirte a un coche compartido](https://fueltic.com/unirse.html)

El contenido **no se edita aquí**: vive en `web/` del repositorio de la app y se publica con
`npm run web:publicar`. Cualquier cambio hecho directamente en este repositorio se pierde en la
siguiente publicación.

> El repositorio conserva el nombre `fuelytics-web` del primer nombre de la app. **No se renombra a
> propósito**: GitHub Pages, el dominio propio y su certificado cuelgan de él, y el nombre no aparece
> en ninguna página desde el 12/08/2026. Renombrarlo sería arriesgar el sitio que Google Play tiene
> registrado a cambio de nada visible.
