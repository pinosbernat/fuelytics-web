# fuelytics-web

Sitio público de **Fuelytics**, la app de registro de repostajes y consumo real.

- [Política de privacidad](https://pinosbernat.github.io/fuelytics-web/privacidad.html)
- [Eliminar tu cuenta](https://pinosbernat.github.io/fuelytics-web/eliminar-cuenta.html)

Existe porque Google Play exige una URL pública donde el usuario pueda solicitar el borrado de
su cuenta sin instalar la app. El código de la aplicación vive en un repositorio privado
aparte; aquí solo están las páginas.

Se genera con GitHub Pages a partir de los Markdown de este repositorio: sin build y sin
dependencias.
